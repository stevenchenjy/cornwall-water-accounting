# Analysis plan — public-source audit first

1. Pin each numeric observation to the exact inspected PDF SHA256, retrieval receipt and physical page. Do not substitute the latest source revision. Preserve original bytes locally.
2. Record report testing coverage, production coverage, billing coverage, daily-billing denominator and measurement boundary independently. An overall January–December report is not confirmation of a billing period. Leave unsupported dates empty.
3. Transcribe all four quantities and displayed percentage precision. AI text-plus-image inspection is `ai_text_and_visual_checked`; reserve `human_verified` for a named person's documented inspection.
4. Annualize daily billed volume only with an explicit denominator/status. The current 365/366-day calculations are scenarios (`assumed_calendar_days`). Compare printed percentages with conditional nearest-unit rounding intervals. Retain 0.05 pp as a labeled diagnostic heuristic. Do not infer actual reporting precision rules from printed digits alone.
5. Produce the [first annual audit](../reports/annual-audit.md) and a descriptive [2024–2025 bridge](../reports/reconciliation-bridge.md). Keep arithmetic contributions separate from record-supported explanatory adjustments. Unknown adjustment amounts are not zero.
6. Review the first table before a final narrative. Challenge page/hash mapping, dates, denominator assumptions, 2020/2022 discrepancies, the contextual 2023 daily billed basis and boundary uncertainty. Record whether review was self-review, another agent or an independent person.
7. Review existing local water/energy work and Water Master Plan scope. Ask which decision the department would use and whether the discrepancy is already explained. See [existing work](existing-work.md).
8. Request 2024/2025 calculation worksheets, daily-billing denominator/coverage, year assignment, adjustments and customer/measurement scope first. Only if unresolved, request monthly production and native bill-cycle volumes, coverage/adjustments and adjacent overlapping cycles. Keep 2020/2022 as specific historical clarification items.
9. Use [hypothesis-evidence.csv](hypothesis-evidence.csv) to test multiple explanations. A July 2024 bill-issuance notice supports an event, not a volume-transfer mechanism. Include formula changes, boundary shifts, correction totals, authorized unbilled use and measurement issues.
10. Stop at a public-report comparability audit if records are unavailable. Expand into monthly reconciliation only after definitions, access and departmental use are confirmed. No causal/leakage conclusion or novelty claim follows from arithmetic consistency alone.
